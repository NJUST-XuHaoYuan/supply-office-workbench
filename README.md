# 供电所工作台

面向基层供电所的岗位协同 H5 产品原型。左侧选择工作，右侧围绕当前事项与工作助手沟通，主视图为“待我处理”和“我在跟进”。

**这是独立产品演示，不是国家电网官方产品。所有业务数据均为演示样例，未连接真实 DSH、AI 模型、营销 2.0 或其他内网业务系统。**

## 运行

需要 Node.js 22.12 或以上版本与 npm。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5174/>。端口被占用时，可运行 `npm run dev -- --port 5175`。

```sh
npm test
npm run build
npm run preview
```

构建输出位于 `manager-page/dist/`，预览地址为 <http://127.0.0.1:4174/>。

## 演示范围

- 所长、营销员、运维采集班长、台区经理四个岗位。
- 串行步骤按责任交接，上游转为跟进，结果回流后由指定人员确认收口。
- 客户服务的独立工作可以并行；任务分组不合并各工单的验收责任。
- 日报、周报拥有独立工作、对话、版本和文本下载，确认报告不会关闭其引用的业务事项。
- 自主工单演示资料准备、人工确认、模拟回执、人员分派和结果反馈。`MOCK` 编号不是真实业务系统工单号。
- “查看详情”呈现资料、分工和沟通记录；“更多”提供简报、成果、归档及演示重置。
- 正文与输入框采用 16px 字号，辅助内容不小于 14px，主要操作区域至少 44px，并适配窄屏。

## 试用路径

1. 默认进入所长岗位，在异常核查事项中输入“同意”，核对助手整理的意见，再点“确认执行”。
2. 切换营销员岗位，处理刚收到的事项，例如输入“采集口径已核对，总表分表统计时点一致，数据完整”。
3. 点“发起工作”，输入“帮我生成本周周报”，可查看正文并继续对话修改。
4. 发起自主工单可输入“为新桥村3号台区创建采集异常核实自主工单”，准备完成后等待人工确认。

对话采用本地预设规则，仅支持代表性演示表达。没有识别的请求会说明未执行，不代表真实 AI 能力。演示不提供实际电力作业指导。

## 浏览器测试

浏览器测试使用独立临时配置，不接管日常浏览器。默认要求本机安装 Google Chrome，并已启动开发服务。

```sh
npm run test:browser
```

也可安装 Playwright Chromium 后运行：

```sh
npx playwright install chromium
```

此时设置环境变量 `WORKBENCH_BROWSER=chromium` 后执行 `npm run test:browser`。其他服务端口可通过 `WORKBENCH_URL` 指定，例如 `http://127.0.0.1:5175/`。

## 代码结构

| 文件 | 用途 |
| --- | --- |
| `manager-page/dialogue.jsx` | 页面、对话、详情、报告预览 |
| `manager-page/workspace.css` | 简洁布局、大字号与窄屏适配 |
| `manager-page/workspace-model.mjs` | 工作筛选与通用内容配置 |
| `manager-page/work-responsibility.mjs` | 可见范围与当前处理责任 |
| `manager-page/dialogue-model.mjs` | 本地对话规则、确认、报告与版本 |
| `manager-page/collaboration-model.mjs` | 演示工作数据、流转与验收 |
| `manager-page/WORKSPACE-PATTERNS.md` | 产品设计约束与实现边界 |

## 数据与边界

记录保存在当前浏览器的 localStorage。岗位切换是单机模拟，不是身份认证；不同电脑之间没有同步，也没有部署公共协同服务。演示记录可从“更多”内重置。

本仓库仅包含独立工作台页面，不包含早期 Electron 桌面应用、浏览器扩展、原始业务材料、个人浏览器配置或密钥。

仓库公开不代表连接了生产业务系统，也不代表完成安全、合规或电力作业审查。请勿将真实客户信息、业务凭证或内部材料提交到公开仓库。
